Save for the whole site

This site is hosted as static files on GitHub Pages, so the only way a browser save can change the site for everyone is to commit the file to the repo (Jcosgrove99/poppy-website-poc). That needs a GitHub token with write access — a fine-grained personal access token limited to this one repo, with Contents: Read and write. Create one at GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.

Your token is kept only in this browser and is sent only to api.github.com. Anyone without a write token can edit the text here, but can't change the live site.

Save writes the new document for the entire site: locally it saves through the included server (npm start); on the public site it commits to both main and gh-pages, updating poppy.json and .well-known/poppy.json together — GitHub Pages then rebuilds (usually about a minute).
